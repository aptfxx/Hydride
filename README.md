# Hydride

Hydride is a fork of Glovium specifically targeted towards MM2. It offers more features than base Glovium, which no other script offers.
If you want to buy Hydride, please check back to this page later. 

Features Glovium Lacks
- Legit Autofarm
- Identify Glovium Users
- Drawing-Level ESP
- Config Support
- Instant Loading
- Killfling
- Non-TP Kill
- [Clientside] All items
- Super XP Autofarm
- Better Longevity
- Triggerbot
- ServerHop


## Fun facts about Hydride 
Hydride has outperformed many other scripts encountered on MM2, some of which have ragequit because they cannot win against me.

The Anti-Fling (even in base glovium!) literally stops 99% of flings.
